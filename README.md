# Juggernaut Event Datapack

A Minecraft 1.21.2 datapack that adds a Juggernaut event game mode for your SMP.

## Features

- 60-second countdown before the event starts
- Random player selection as the Juggernaut
- Enhanced abilities for the Juggernaut (strength, resistance, speed, etc.)
- Team-based gameplay (Juggernaut vs Survivors)
- Win conditions for both teams
- Rewards for winners
- Custom sounds and visual effects

## Installation

1. Download the `juggernaut_event` folder
2. Place it in your world's `datapacks` folder
3. Run `/reload` in your world
4. Start the event with `/function juggernaut:start`

## Commands

- `/function juggernaut:start` - Start the Juggernaut event
- `/function juggernaut:stop` - Stop the event and reset
- `/function juggernaut:reset` - Reset all players and scores

## Gameplay

1. Run the start command
2. Wait 60 seconds for the Juggernaut to be selected
3. The selected player becomes the Juggernaut with special abilities
4. All other players must work together to defeat the Juggernaut
5. Event ends when either the Juggernaut is defeated or all survivors are eliminated
